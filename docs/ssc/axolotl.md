# 美西螈形态

---

## 形态概述

美西螈形态在水中非常灵活，同时有着较高的生命上限与较强的再生能力，但需要时刻保持湿润。[^source]

### 挖掘

在美西螈形态第三阶段及后续阶段下在水下挖掘时不会受到水下挖掘速度惩罚。

### 近战攻击

美西螈形态的近战攻击与正常玩家无异。

### 饥饿

在美西螈形态第二阶段及后续阶段下食用肉类食物所恢复的饥饿值会有所增加。新饥饿值的计算公式如下：

$$
y = \max ((x+2)\times 1.2,4)
$$

其中 x 为原饥饿值， y 为新饥饿值。

#### 步行

!!! warning 本条目需要验证：第二、三阶段是仅在指定方块上才会减速还是只要在陆地上就会减速 !!!

美西螈形态在第二阶段及后续阶段下在陆地上的步行速度会变慢。

#### 疾跑

美西螈形态在永久阶段下且有湿润度的情况下疾跑会被替换为 [踏浪](# 踏浪)。

#### 潜行

美西螈形态在第三阶段及后续阶段下的潜行会被替换为 [爬行](爬行)。

#### 游泳

!!! warning 本条目需要验证：游泳速度在第一、二、三阶段是否会有所提升 !!! !!! warning 本条目缺少数据 !!!

美西螈形态的所有阶段在水中的游泳速度与速泳速度均快于原版玩家，且在永久阶段下完全进入水中后会自动变为速泳。

| 阶段     | 变化                              | 速度（米 / 秒）[^1] |
| -------- | --------------------------------- | ------------------- |
| 第一阶段 | 基础游泳速度增加至原版玩家的 220% |                     |
| 第二阶段 | 基础游泳速度增加至原版玩家的 250% |                     |
| 第三阶段 |                                   |                     |
| 永久阶段 |                                   |                     |

[^1]: 此处的速度为水平游泳速度

#### 速泳

美西螈形态在永久阶段下速泳将不再额外消耗饥饿值。

#### 爬行 {# 爬行}

美西螈形态在第三阶段及后续阶段下的爬行速度均快于原版玩家。

### 湿润度

!!! warning 本条目需要验证：滞留型药水是否能恢复湿润度 !!!

美西螈形态在第三阶段及后续阶段下其氧气值会变为湿润度，上限 300 点。

#### 恢复

!!! warning 本条目缺少数据 !!!

湿润度可以通过 ** 在水中完全浸没、暴露在雨中、饮用水瓶或药水、使用喷溅型药水或滞留型药水、水肺效果 ** 恢复。

| 恢复方式       | 恢复效果            |
| -------------- | ------------------- |
| 在水中完全浸没 | 每刻恢复 4 点湿润度 |
| 暴露在雨中     |                     |
| 饮用水瓶或药水 | 恢复 300 点湿润度   |
| 水肺效果       |                     |
| 使用喷溅型药水 | 恢复 150 点湿润度   |
| 使用滞留型药水 |                     |

#### 消耗

进入踏浪状态或使用水流爆破均会消耗湿润度。
