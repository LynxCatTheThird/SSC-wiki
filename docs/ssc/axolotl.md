# 美西螈[^source]

美西螈线围绕水下生存、氧气和水流机动展开。离水惩罚随阶段变化，后期可以匍匐、从水中跃出、通过药水补充空气，并发动水流冲刺或爆发动作。

| 阶段 | 主要能力 | 主要限制 |
| --- | --- | --- |
| `axolotl_0` | 游泳速度、屏息 | 离水/鼓起状态减速 |
| `axolotl_1` | 水下呼吸、再生、出水跳、鱼类食物增益 | 头盔受限、食性偏肉食 |
| `axolotl_2` | 水下呼吸、潮湿生命增益、减摔、匍匐、水流喷发 | 干燥减速，依赖空气/水环境 |
| `axolotl_3` | 水中视觉、疾跑游泳、水爆、冲刺攻击、台阶跨越 | 地面移动削弱，仍受水/氧气体系约束 |

## 已确认数值

| 阶段或条件 | 数值 | 玩家感受 |
| --- | ---: | --- |
| `axolotl_0` 游泳速度 | 基础水速倍率提高 120% | 水中移动约为原版的 2.2 倍 |
| `axolotl_1` 游泳速度 | 基础水速倍率提高 150% | 水中移动约为原版的 2.5 倍 |
| `axolotl_2` 湿润时 | 最大生命值增加 6 | 空气值大于 0 时多 3 颗心上限 |
| `axolotl_3` 水外疾跑 | 移速提高 65% | 有空气时陆地疾跑很快 |
| `axolotl_3` 水外站立 | 移速降低 30% | 不游、不跑时最慢 |

空气值就是这条形态线的湿润度，消耗和恢复见 [SSCA 数值系统](../ssca/numeric-systems)。

## 空气与药水

二、三阶段注册了从普通药水和喷溅药水获取空气的能力。具体可恢复量取决于能力实现，不能仅凭物品名称推断。

## 装备

中期起头部护甲受到限制。最终阶段还会改变手臂渲染、潜行和疾跑动作，第一人称表现可能与普通玩家不同。
