# 阿澪

阿澪是荧光幼灵的剧情特殊变体，不是进化石直接产物。源码注册时复用荧光幼灵的能力类、体型缩放（`0.75`）和湿润度/闪避/免摔落能力；区别由能力管理器按 `axolotl_aling` ID 判断。[^source]

### 已核实差异

- **潮汐波动**：飞行上限与牵引时长各乘 `1.2`。当前实现的基础值分别为 160 tick（8 秒）和 170 tick（8.5 秒），因此阿澪为 192 tick（9.6 秒）和 204 tick（10.2 秒）。
- **法阵激光**：阿澪自带三法阵连发，不需要海晶荧光坠；每道激光基础 12 点物理伤害，阿澪倍率为 `1.2`，实际为 **14.4 点**。增强射程为 24×1.2，即 28.8 格；判定半径为 0.75×1.2，即 0.9 格。
- **连发限制**：一次组合最多 3 道，每道发射后累计 120 tick（6 秒）冷却；组合期间移动速度降低 50%，5 秒未继续发射或法阵用尽即结束。

阿澪的解锁必须满足潮汐之灵剧情条件：处于荧光幼灵、取得 `ssc_addon:tide_spirit_power` 成就，并在诅咒之月夜晚入睡完成剧情睡眠。源码没有把它实现为普通路线节点。

获得方式可能由剧情或整合包配置决定。

[^source]: SSCA `SscAddonForms.java`、`FluorescentLaserManager.java`、`TidalOrbEntity.java`、`TideSpiritStoryManager.java` 与 `form_axolotl_aling_*.json`；上游核对时间 2026-09-09。
