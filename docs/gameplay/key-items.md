# 关键物品

SSC 的形态推进物品以未加工月之尘和月尘基质为基础。本页列出当前 1.10.0 资源文件可直接确认的配方与用途。

## 起点物品

| 物品 | 配方 | 用途 |
| --- | --- | --- |
| 未加工月之尘 | 青金石和紫水晶碎片以 `2×2` 对角方式各放 2 个，产出 4 个 | 手册、月尘基质及后续材料的基础原料 |
| 变形者手册 | 未加工月之尘 + 书，无序合成 | 查看自身状态、形态能力与提示 |
| 月尘基质 | 未加工月之尘 + 蜂蜜瓶，无序合成 | 四种推进/抑制物品的共同基底 |

取得未加工月之尘会解锁手册配方；取得月尘基质会解锁普通和强化催化剂、抑制剂配方。在**诅咒之月期间**，由玩家（或其驯服生物）击杀 Mob 时，当前代码另有 `45%` 概率掉落 1 个未加工月之尘。该注入还受伤害来源、实体类型及其他模组 Mixin 兼容性影响。

## 催化剂

| 物品 | 配方 | 主要行为 |
| --- | --- | --- |
| 催化剂 | 下界疣 + 月尘基质 + 碗 | 激活已有转化效果，或尝试把当前形态推进一阶段 |
| 共鸣催化剂 | 回响碎片 + 月尘基质 + 碗 | 只对带 `CanTFToFinalForm` 标记的形态尝试最终转化 |

普通催化剂不是“随机换形态”道具。它根据当前形态及 `Item` 变身原因查询下一形态；若形态抗拒、免疫、已经到顶或没有合法目标，物品仍可能被吃掉但不发生变化。

:::danger 最终形态通常不可逆
共鸣催化剂的游戏内提示明确把最终推进描述为永久变化。使用前先确认对应形态的第 4 阶段限制和恢复方法。
:::

## 抑制剂

| 物品 | 配方 | 主要行为 |
| --- | --- | --- |
| 抑制剂 | 金苹果 + 月尘基质 + 碗 | 清除未激活转化效果，或尝试后退一阶段 |
| 强力抑制剂 | 附魔金苹果 + 月尘基质 + 碗 | 使用强化的后退规则，但仍受形态免疫标记限制 |
| 极限抑制剂 | 创造模式物品，无普通配方 | 强制恢复至原始变形者，也能清除转化效果 |

抑制剂不会无条件治愈一切。`InhibitorResist`、`InhibitorImmune`、特殊形态规则和附属模组都可能阻止回退；极限抑制剂属于管理或测试手段。

## 使用细节

- 四种普通/强化物品都是食物类物品，可在饱食时使用；
- 堆叠上限为 16；
- 食用后返还碗，背包满时碗会掉在地上；
- 创造模式不会消耗物品；
- 它们被加入 SSC/Origins 的饮食忽略标签，形态食性不应阻止使用。
