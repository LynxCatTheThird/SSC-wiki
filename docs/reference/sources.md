## 内容核验规则

源代码、资源和目标版本的游戏测试优先于旧 Wiki。旧 Wiki 只在内容与当前版本一致、且没有更直接的代码证据时引用。

页面状态分为：

- `verified`：已经对照代码或游戏测试；
- `partial`：只有部分内容确认；
- `outdated`：仅供旧版本参考；
- `experimental`：测试功能；
- `community`：社区移植或附属内容。

## 许可证边界

SSC 与 SSCA 的代码、资源、文档和故事内容可能适用不同许可证。转载故事文本、模型、纹理或游戏内书籍前必须核对原项目许可；必要时只提供摘要、索引和来源链接。

本站是非官方社区文档，不代表模组作者，也不出售模组或文档内容。
