# 操作、HUD 与白名单

SSCA 多数主动能力共用“主技能”和“次要技能”两个逻辑按键。不同形态会把同一个按键解释为不同技能，部分能力还区分按下、长按、松开、再次按下或潜行组合。[^source]

## 先绑定技能键

默认情况下，SSCA 跟随 SSC 的：

- `主动技能 1`：SSCA 主技能；
- `主动技能 2`：SSCA 次要技能。

SSC 1.10.0 源码把主动技能 1 到 6 的默认按键全部设为“未绑定”。因此首次游玩应在 Minecraft 的按键设置中自行绑定前两个主动技能，不能假定主技能默认是 G。

SSCA 还提供按形态覆盖：从 Mod Menu 打开 SSCA 设置，进入“特殊键位设置”，选择形态后启用自定义键位，并分别绑定主、副技能。启用后，该形态只读取自定义按键，不再响应 SSC 的全局主动技能键；按 `Esc` 可以解绑。

:::warning GUI 打开时不会触发技能
SSCA 明确在任何界面打开时阻止虚拟技能键触发。绑定完成后应回到游戏世界测试。
:::

## 常见操作类型

| 操作             | 常见解释                                         |
| ---------------- | ------------------------------------------------ |
| 点按主/副技能    | 立即释放、切换模式或开始技能                     |
| 按住后松开       | 蓄力并按蓄力档位释放                             |
| 技能期间再次按下 | 提前结束、引爆或进入下一段                       |
| 潜行 + 技能      | 使用替代模式；具体是否支持取决于形态             |
| 冲刺键           | 美西螈等个别形态还有独立的移动处理               |
| 左键/右键物品    | 某些形态技能通过特定物品交互触发，不走主副技能键 |

具体组合必须以对应形态页为准。不要把另一个形态的“长按”规则套到当前形态。

## HUD

SSCA 使用通用资源条注册表显示不同形态的核心资源：

| 资源          | 默认上限 | 常见形态                         |
| ------------- | -------: | -------------------------------- |
| SP 悦灵 Mana  |      200 | SP 悦灵                          |
| SSC Mana 适配 |      100 | 使魔、蜘蛛等沿用 SSC Mana 的形态 |
| Blood         |      100 | 吸血蝙蝠                         |
| Soul Energy   |      100 | 冥裁者                           |
| Frost/Mana    |      100 | 雪狐扩展形态                     |
| Seed          |       10 | 寄生果蝠                         |

主、副技能冷却使用两条独立资源驱动 HUD。客户端配置默认显示冷却条和剩余秒数；部分技能会同时锁定两条冷却，或在释放失败、被打断时写入惩罚冷却。

HUD 的本能、能量和冷却位置可在可视化位置编辑器中拖动。客户端配置只影响本机显示，不会改变服务端技能判定。

## 技能白名单

运行 `/ssc_addon my_whitelist` 打开自己的白名单。它控制攻击性技能跳过谁，以及治疗/强化技能把谁视为友方。

默认 `whitelistEnabled=true` 时：

- **名单完全为空**：攻击技能默认保护其他玩家、在线玩家拥有的驯服生物，以及带主人标记的召唤物；治疗/强化也把这些对象视为友方；
- **名单出现任何玩家或生物条目**：切换为仅名单模式，只有名单内玩家、生物，以及名单玩家拥有的驯服物/召唤物受保护或接受强化；
- 自己始终受自己的友方判定保护；
- 生物条目通过“友军标记”物品加入，再从 GUI 的生物页移除。

:::danger 添加第一项会改变整份名单的语义
加入一个队友后，其他未加入的玩家不再享受“空名单默认保护”。组队前应把所有需要保护的成员都加入，而不是只加一人测试。
:::

服主关闭 `whitelistEnabled` 后，攻击性技能不再对白名单目标提供保护；治疗/强化仍会排除敌对生物、Monster 和未驯服的可激怒生物。这不是“所有技能完全忽略阵营”的开关。

## 技能不响应的排查顺序

1. 确认 SSC 主动技能 1/2 已绑定，或当前形态的自定义键位已启用且不是“未绑定”。
2. 关闭聊天、手册、物品栏和配置界面后再试。
3. 确认形态确实拥有该技能；部分加点路线必须先解锁节点。
4. 查看主/副冷却条和形态资源是否足够。
5. 检查是否处于眩晕、装死、蓄力或其他禁止输入状态。
6. 让服主检查 `disabledSkills` 与玩家级 `ssc_skill_blocked:*` 标记。
7. 检查客户端日志是否出现 `Failed to register client keybindings`；出现时通常是 SSC/SSCA 版本接口不匹配。
