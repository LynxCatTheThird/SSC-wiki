# SSCA 扩展总览

SSCA 是 SSC 的社区附属模组，为原版形态体系添加 SP 形态、进化路线、技能、资源、物品、效果、实体和故事内容。

## 当前内容方向

- 美西螈、使魔狐、雪狐、悦灵、野猫、豹猫、堕落悦灵等 SP/扩展形态；
- 阿努比斯之狼 SP 与金沙岚；
- 吸血蝙蝠、寄生果蝠；
- 月织蛛和跳蛛；
- 进化树、进化石和月髓相关系统；
- Mana、Soul、Blood、Seed 等形态专属资源；
- 能量网络、容器和转换方块。

SSCA 是社区项目，虽然内容和维护成熟度较高，但仍应以 SSCA 自己的发行说明、源码和版本匹配关系为准。

## 版本基线

首发文档按 Minecraft 1.20.1 Fabric、SSCA 8.0.0-beta.2 和 SSC 1.10.0 组织。beta 构建可能依赖 SSC 测试版本，安装前请核对发行版说明。
