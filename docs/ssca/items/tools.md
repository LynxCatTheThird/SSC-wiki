# 道具与方块

## 形态道具

| 名称 | ID | 主要用途 |
| --- | --- | --- |
| 水矛 | `ssc_addon:water_spear` | SP 美西螈和相关技能生成或使用的水系武器 |
| 友军标记 | `ssc_addon:friend_marker` | 将生物加入自己的技能白名单 |
| 消除友军标记 | `ssc_addon:clear_friend_marker` | 移除生物的友军标记 |
| 治疗术 | `ssc_addon:allay_heal_wand` | 悦灵路线的手持治疗工具 |
| 悦灵唱片机 | `ssc_addon:allay_jukebox` | 触发悦灵路线的音乐增益 |
| 药水包 | `ssc_addon:potion_bag` | 收纳并快速使用相关药水 |
| 雪球发射器 | `ssc_addon:snowball_launcher` | SP 雪狐的连续雪球武器，弹容量 20 |
| 美西螈加湿器 | `ssc_addon:portable_moisturizer` | SP 美西螈离水时维持湿润度；可升级和补充 |

## 能量系统方块

能量储罐、能量装瓶器、能量转变器、能量汲取器、药品存储箱和创造能量储罐组成一套能量与药水处理设备。普通设备用于储存、装瓶、转换或抽取能量；创造能量储罐是创造模式测试设备，不能当作生存获取来源。

## 药水与唱片

| 名称 | 作用 |
| --- | --- |
| 通用能量药水 | 为支持的资源条补充能量 |
| 无限压缩能量药水 | 三件套配方中的高容量能量来源 |
| 凋零药水 | 施加凋零相关效果 |
| 音乐唱片 | 供悦灵唱片机读取，触发音乐状态 |

## 其它

蛛网膜用于月织蛛的铺网体系；女巫使魔蛋和野生美西螈幻形者蛋用于测试或召唤对应实体。它们的获取方式受战利品表、创造物品栏和服务器配置影响。
