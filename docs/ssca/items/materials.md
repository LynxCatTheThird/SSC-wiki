# 材料与素材

## 当前可见材料

| 名称 | 用途 | 备注 |
| --- | --- | --- |
| 塑形核心 | 月髓十字环、进化石和多种饰品配方 | 由 SSC 提供的核心材料，SSCA 只引用它 |
| 月尘纯晶、月尘水晶碎片 | 进化用品与饰品 | 名称随语言文件显示，配方以当前版本为准 |
| 珊瑚球 | 材料类彩球 | 由各类珊瑚制作，主要用于装饰或相关配方 |
| 海晶碎片 | 海晶荧光坠 | 荧光幼灵路线的专属材料 |

## 进化碎片

官方 Wiki 导航仍列出暗影、夜视、终幕、猎杀和幽匿五类“进化碎片”，但上游当前资源树将它们标为未实装备份内容。它们不应被当作现版本必需材料，也没有列入本站的可用配方。

## 原版物品改动

SSCA 会为不死图腾、信标等原版物品增加形态相关交互或兼容逻辑。原版物品本身的合成和获取方式不变；新增效果只在对应形态、饰品或技能条件满足时出现。
