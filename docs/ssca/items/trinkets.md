# 饰品

除特别注明外，饰品通过对应配方或结构宝箱获得，并依赖 Trinkets 提供的饰品栏。形态专属饰品只在匹配形态中生效。[^source]

| 饰品 | 适用形态 | 效果摘要 |
| --- | --- | --- |
| 蓝火护符 | SP 使魔 | 强化苍蓝火环 |
| 戏剧铃铛 | SP 使魔 | 危急时提供随机传送保命机会 |
| 暴风雪储罐 | SP 雪狐 | 储存并补充霜寒或雪球资源 |
| 霜之护符 | SP 雪狐 | 强化冰霜技能 |
| 保命猫尾 | SP 野猫 | 承受一次致死伤害后进入冷却 |
| 隐匿斗篷 | SP 野猫 | 真实隐身持续时间增加 2 秒，冷却增加 2 秒 |
| 梦魇戒指 | 食梦魔 | 强化梦境与恐惧循环 |
| 寒棘项圈 | 寒棘狐 | 强化冰棘技能 |
| 毒液腺体 | 跳蛛 | 强化毒素效果 |

## 不可装备饰品

美西螈加湿器和雪球发射器属于手持功能道具，不占饰品栏。它们分别服务 SP 美西螈的湿润度管理和 SP 雪狐的远程输出。

:::note 获取提示
部分饰品只注册了结构宝箱战利品，部分只注册了工作台配方。具体掉落位置和配方请以 JEI/REI/EMI 在当前整合包中的显示为准。
:::
