# 进化系统

SSCA 的进化系统由进化组件、进化管理器、进化节点、路线和形态树组成。玩家可以沿形态专属路线解锁更高阶能力或 SP 形态。

## 主要概念

- **进化树（Tree）**：某一形态线的节点集合；
- **节点（Node）**：一个里程碑、能力或解锁条件；
- **路线（Route）**：节点之间的前后关系；
- **进化点/资源**：用于解锁或转职的持久化玩家数据；
- **进化书/界面**：客户端查看和选择进化路线的界面。

源码中已经注册使魔狐和美西螈等进化树，并提供管理命令用于解锁或重置。具体节点成本和路线应按当前 SSCA 数据与游戏内界面逐项记录。
