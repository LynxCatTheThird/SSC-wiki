# 第一次变身

SSC 的核心循环是：获得诅咒影响，在诅咒之月期间逐步转化为不同生物形态，并在每个形态阶段获得新的能力与限制。

## 先理解三个概念

- **形态（Form）**：玩家当前使用的生物形态。形态可以有阶段、最终形态和子形态。
- **诅咒之月（Cursed Moon）**：推动转化进程的时间/世界事件。配置可以改变其行为。
- **Instinct**：与形态和行为相关的机制。不同形态可能拥有不同的本能、限制或免疫标记。

## 建议流程

1. 完成安装并进入新世界。
2. 阅读游戏内的 Book of Shape Shifter，确认当前版本提供的提示。
3. 观察诅咒之月相关提示，不要在不了解限制时贸然进入危险区域。
4. 按形态页面的获取条件推进阶段。
5. 变身后先测试移动、跳跃、挖掘、攻击和物品交互，再开始长期探索。

:::warning 版本差异
形态获取条件、能力按键和技能数值会随 SSC/SSCA 版本变化。本页只描述总体流程，不替代具体形态页面。
:::
