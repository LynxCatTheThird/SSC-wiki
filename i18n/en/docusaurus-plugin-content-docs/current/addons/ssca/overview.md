# SSCA overview

Shape Shifter Curse Addon (SSCA) is an independent community project built on SSC's form and animation framework. It adds endgame forms, evolution routes, combat skills, resources, equipment, story content, and HUD features.

The addon uses the historical `my_addon` namespace while its mod ID is `ssc_addon`. The namespace in an item or form ID is therefore not a reliable indication of which jar provided it.

New players can select the evolved Familiar Fox or evolved Axolotl route from the SSC starter book. Players who reach an SSC stage-4 form can use the Moon Marrow Cross or an evolution stone to enter an SSCA branch. These items have different targets and failure rules.
