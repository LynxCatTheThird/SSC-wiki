# Command reference

SSC and SSCA commands are intended for testing, administration, and recovery. Use Minecraft's command autocomplete (`/` then press Tab) to see the exact subcommands exposed by your installed build; command names can change between releases.

Run commands with the required permission level. In a test world, use the form and item identifiers shown on the relevant page, including the `shape-shifter-curse:` or `my_addon:` namespace. Do not paste a command from a different version without checking autocomplete first.

The Chinese command page contains the current command matrix and examples; the English version will be expanded alongside it.
