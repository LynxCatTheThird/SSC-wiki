# Instinct

Instinct is the main progression resource for normal SSC forms. It is a player-facing value: staying in your form, using its abilities, and meeting its preferred conditions helps you raise it; hostile environments, unsuitable food, or repeated inhibitor use can slow recovery.

Keep instinct high before attempting a stage change. The exact threshold and recovery action differ by form, so the form pages list the practical loop in plain language. SSCA special forms disable this system and use their own resources instead.
