# Key items

SSC uses transformation effects, catalysts, and inhibitors. A catalyst opens or advances a route; an inhibitor reverses a normal form. SSCA adds the Moon Marrow Cross, evolution stones, and form-specific materials. These items are not interchangeable.

Before using one, confirm the current form, stage 4 requirement, Cursed Moon requirement, and failure result on the linked route page. SSCA special forms are inhibitor-immune, so a normal inhibitor cannot restore them.

The Chinese pages currently contain the complete recipe and drop tables; the English item reference is being expanded from the same source files.
