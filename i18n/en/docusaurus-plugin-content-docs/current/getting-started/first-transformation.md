# Your first transformation

SSC begins with a transformation effect. Find the anomalous creature described by the in-game book, defeat it, and collect the dropped effect item. Use the item while the target form is available; the first transformation starts at stage 0.

Stages advance through experience and the form's own conditions. Read [forms and stages](../gameplay/forms-and-stages) before entering combat: some forms need instinct, a minimum stage, or a specific environment.

If the effect does not apply, check that the jar versions match, the target is not a special SSCA form, and no inhibitor or conflicting mod is active. The Chinese reference contains the exact drop tables while this page is being expanded.
