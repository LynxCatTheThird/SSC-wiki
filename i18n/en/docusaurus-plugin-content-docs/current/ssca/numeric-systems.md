# Numeric systems

SSCA replaces SSC's ordinary instinct loop on special forms with explicit resources. Depending on the form, the HUD can show Mana, wetness, blood thirst, frost, souls, seeds, lives, or web affinity. Maximum values, regeneration, thresholds, and cooldowns are form-specific.

Read the resource bar as a gameplay constraint: high Mana can enable a shield, low wetness can cause dehydration, and soul or seed charges are spent by the matching skill. The [Chinese numeric reference](pathname:///zh-CN/ssca/numeric-systems) contains the current ECharts plots and verified formulas.
